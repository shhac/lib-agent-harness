# v0.31.0

Nothing in this release needs a consumer change.

- A command sandbox on macOS may now bind and connect to Unix-domain sockets
  within its own private scratch (`TMPDIR`, `HOME`) and a writable workspace,
  as Linux pathname sockets already could. A project's tests that start a
  daemon on a socket and talk to it, which were refused, now run. Every other
  socket stays out of reach, the caller's own included: the profile allows
  only `subpath`s of what the sandbox may write, and the existing canary that
  a socket outside cannot be reached still holds.
- Socket paths are limited to about a hundred bytes. A caller whose
  `RuntimeHome` is deep makes every scratch path deep, so choose a short one
  where commands' tests use sockets.

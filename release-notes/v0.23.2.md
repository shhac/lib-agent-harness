# v0.23.2

A command sandbox fix. No API changes.

- macOS: sandboxed commands can create and edit git repositories inside their
  private `TMPDIR`, for example test fixtures that run `git init`. The
  workspace's own `.git`, and any new repository nested in the workspace,
  are still write-protected. This matches the Linux sandbox. The profile is
  now `seatbelt-workbench-v6`, so cached proofs are taken again on first open.

# v0.24.1 (unreleased)

Hosted API workbench run_command retains the shared runner's single bounded
dropped-PATH stderr note on failures, including unknown outcomes, cancellation,
deadlines, closure and generic errors. Captured failures return error-marked JSON
with stderr, truncated, error, exit_code and timed_out; no-capture failures retain
legacy text. Admission and unknown-side-effect accounting are unchanged.

Deprecated session.CommandSandbox.Start can return a settled non-nil handle
together with an error after launch. Callers should inspect that handle's Result
for diagnostics; pre-launch failures still return nil. Result remains stable.

session.CapabilityError.ProofStep and harness.ErrorFacts carry fixed shared
proof-step facts. Unknown steps are empty; no-step error wording is unchanged.
Shared PATH/read policy, sandbox proofs, capability claims and the v0.24.0
file-tool refusals are unchanged.

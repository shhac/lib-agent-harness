# v0.32.3

Nothing in this release needs a consumer change.

- The sandbox edge finds npm Codex's native executable where Codex 0.160 and
  0.166 put it (`vendor/<triple>/bin/codex`), as well as the older
  `vendor/<triple>/codex/codex`. Before this, an npm-installed Codex of those
  versions was refused under the edge with "npm Codex needs its platform
  native executable installed".
- The installed-CLI edge canary takes the off-machine control CI proves and
  passes in (`AGENT_HARNESS_TEST_LOOPBACK_CONTROL`), as the real boundary test
  does since v0.32.2.

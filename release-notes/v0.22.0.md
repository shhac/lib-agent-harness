# v0.22.0 (pending release)

- Add sandbox.OpenWorkspace and the sandbox package for confined file access;
  its API is
  provisional until the command sandbox moves. Session APIs are unchanged.
- Add session.OpenCommandSandbox for proved shell execution without a model
  session, with bounded Run and long-running Start/Stop/Done/Result.
- Share execution with Workbench.Commands, retain its environment rules and
  tool-result contract, and add standalone recovery locks and Close reaping.
- Prove macOS inbound localhost access. Linux Run can prove its own private
  localhost; Start with Loopback refuses because the host cannot reach it.
  Windows remains unsupported. harness.Support claims are unchanged.
- Distinguish standalone Close cancellation as CommandSandboxClosed when the
  caller context remains live; hosted run_command retains context.Canceled.
- Preserve Linux's full proof on every Open and session launch/resume. macOS
  alone reuses matching cached evidence. Linux own-localhost proof requires
  OpenBSD nc (netcat-openbsd), not traditional or BusyBox nc.

Additive minor release. No consumer migration is required. Publish/tag after
the macOS, Linux (both supported bubblewrap jobs) and Windows CI checks pass.

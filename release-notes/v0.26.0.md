# v0.26.0

- New `harness.Describe(engine)` returns an engine's label, transport, default
  CLI binary, home variable and default home, so an application can present and
  locate every engine the library knows without its own per-engine table.
- Sessions now find every engine-specific behaviour through one registry of
  engines: wire dialect, defaults and environment rules, initialization and
  notices, turn start, interrupt and steer, and telemetry reads
  (design-docs/2026-10-04-engine-adapters.md). Behaviour is unchanged; goldens
  pin each engine's wire bytes, normalized options, Policy JSON and environment
  rules.
- Selected loopback ports (LAH-24) were landed and reverted within this
  release: real macOS showed Seatbelt cannot confine binds to loopback. They
  return once each platform can prove them.

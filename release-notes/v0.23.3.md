# v0.23.3

No API changes.

- macOS: the command sandbox answers `uname(3)`, which needs the
  `kern.version` and `kern.hostname` sysctls. Node reads it as it loads its
  `os` module and aborted when refused, so project checks that ran npm
  failed. The profile is now `seatbelt-workbench-v7`.
- The launch sweep finds descendants in a hidden environment before the
  group kill, so it no longer misses them (LAH-16).
